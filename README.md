## 2. Deskripsi Proyek

UTS_Profile merupakan website yang dibuat untuk memperkenalkan diri kepada pengunjung. Website ini berisi informasi mengenai profil pribadi, riwayat pendidikan, keahlian, pengalaman atau proyek, serta informasi kontak.

Website ini dibuat menggunakan HTML, CSS, dan PHP. Desain website menggunakan tampilan yang sederhana dan responsive sehingga dapat menyesuaikan ukuran layar laptop, komputer, tablet, maupun smartphone.

## 3. Fitur Website

Berikut beberapa fitur yang tersedia pada website:

1. Beranda: Menampilkan halaman utama dan perkenalan singkat.
2. Tentang Saya: Menampilkan informasi mengenai profil pribadi.
3. Pendidikan: Menampilkan riwayat pendidikan.
4. Keahlian: Menampilkan kemampuan yang dimiliki.
5. Pengalaman/Proyek: Menampilkan pengalaman atau proyek yang pernah dikerjakan.
6. Kontak: Menyediakan formulir bagi pengunjung untuk mengirimkan pesan.
7. Fitur Pencarian: Membantu pengunjung mencari informasi tertentu pada website.
8. Penyimpanan Pesan: Pesan yang dikirim melalui formulir kontak diproses menggunakan PHP dan disimpan ke dalam file `pesan_kontak.txt`.
9. Responsive Design: Tampilan website menyesuaikan ukuran layar perangkat.

## 4. Teknologi yang Digunakan

- HTML: Digunakan untuk membuat struktur halaman website.
- CSS: Digunakan untuk mengatur warna, ukuran tulisan, tata letak, dan tampilan website.
- PHP: Digunakan untuk memproses formulir kontak dan fitur pencarian.
- XAMPP: Digunakan sebagai server lokal untuk menjalankan website PHP.
- Visual Studio Code: Digunakan untuk menulis dan mengedit kode program.

## 7. Cara Menjalankan Website

Untuk menjalankan website melalui localhost, ikuti langkah berikut:

1. Buka aplikasi XAMPP.
2. Aktifkan Apache.
3. Simpan folder website di dalam folder `htdocs`.
4. Buka browser Google Chrome.
5. Ketik alamat `http://localhost/UTS_Profile/`.
6. Tekan Enter untuk membuka website.
